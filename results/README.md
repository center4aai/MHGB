# Released evaluation results

Per-model scores for all 12 models of the paper, over the **full 300-fabula benchmark**
(not just the public subset). These files let anyone recompute the paper's headline
numbers without running a single model.

## What is here

```
results/
├── <experiment>/
│   ├── gap_records.jsonl     one record per fabula: closed score, open score, GAP, quadrant
│   ├── agg_*.csv             means by mode, task type, reasoning depth, branch of law
│   └── gap_*.csv             GAP aggregated by model, task type, reasoning depth
└── statistics/               regenerated by scripts/reproduce_paper_stats.py
    ├── bootstrap_gap_ci.csv
    ├── closed_ci.csv
    ├── open_ci.csv
    └── paired_test_results.csv
```

Each `gap_records.jsonl` line holds exactly these fields:

```
model_name, task_id, task_type, hop_group, branch_of_law,
closed_final_score, open_final_score,
norm_coverage_gap, step_correctness_gap, answer_correctness_gap,
final_score_gap, quadrant
```

No fabula text, no questions, no model responses — identifiers and numbers only. The
tasks themselves cannot be reconstructed from these files, which is why they can be
released in full while the task set is tiered (see the main `README.md`).

`n_pairs` is below 300 for four models (GPT-4o 276, DeepSeek-R1 671B 287, YandexGPT 287,
o3 293): on the deepest tasks the seed norms alone exceed those models' input windows, so
those fabulas are excluded for them. This is a property of the corpus, not of the
pipeline.

## Reproducing the paper's tables

```bash
uv run python scripts/reproduce_paper_stats.py
```

Runs in seconds, no API keys, no GPU. Regenerates `statistics/` and prints:

| Paper table | Reproduced from |
|---|---|
| Main results (closed FS, open FS, GAP) | `gap_records.jsonl`, means per model |
| Bootstrap 95% CI and paired *t*-test on GAP | `bootstrap_gap_ci.csv`, `paired_test_results.csv` |
| Closed-book Final Score with CI | `closed_ci.csv` |
| Quadrant percentages | `quadrant` field of `gap_records.jsonl` |
| Final Score by task type and by depth | `agg_*.csv`, `gap_*.csv` |

Bootstrap uses 2,000 resamples with seed 42, so the intervals come out identical to the
published ones rather than merely close.

## What is not here

Per-response records (`results.jsonl`) with the raw model outputs are not released.
Consequently three appendix analyses cannot be recomputed from this directory and are
skipped by the script: cross-judge Cohen's κ, norm-coverage confidence intervals, and
weight-sensitivity Kendall τ. They are reported in the paper's appendices.
