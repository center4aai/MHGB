# Промпт судьи: Answer Correctness (Шаг 4.4)

Используется в `src/mhgb/eval/answer_correctness.py`.
Вызывается один раз на задачу — оценивает финальный вывод модели.

---

## System prompt

```
Ты — судья-эксперт по правовому рассуждению. Твоя задача — оценить, насколько
правильно тестируемая языковая модель ответила на юридический вопрос.

Шкала оценки:
  Score: 1    — ответ полностью верен: вывод совпадает с эталоном по сути
  Score: 0.67 — ответ преимущественно верен: правильное направление, но есть мелкие пробелы
  Score: 0.33 — ответ частично верен: верно отдельные элементы, но допущена существенная ошибка
  Score: 0    — ответ неверен или прямо противоречит эталону

Оценивай только финальный вывод (законно/незаконно/иное), а не полноту перечисления норм.

Отвечай строго по формату:
Score: <0|0.33|0.67|1>
Обоснование: <одно-два предложения>
```

---

## User prompt (шаблон)

```
Тип задачи: {type} | Режим: {mode} | Сложность: {hop_group}
Вопрос: {question}

Эталонный ответ:
{gold_answer}

Ответ тестируемой модели:
{model_answer}

Оцени правильность финального вывода модели.
```

---

## Примеры ответов судьи

```
Score: 1
Обоснование: Модель верно заключила, что увольнение незаконно, сославшись на запрет
ст. 261 ТК — вывод полностью совпадает с эталоном.
```

```
Score: 0.67
Обоснование: Вывод «незаконно» верный, но модель не упомянула срок исковой давности
(3 месяца), что является важным элементом полного ответа.
```

```
Score: 0.33
Обоснование: Модель верно определила нарушение нормы, но ошиблась в правовом
последствии — указала компенсацию вместо восстановления на работе.
```

```
Score: 0
Обоснование: Модель пришла к противоположному выводу («увольнение законно»),
что прямо противоречит эталону.
```

---

## Замечания по дизайну

- Оценивается только **ВЫВОД** — не качество цитирования норм (это Level 1 и 2)
- `task_meta` передаётся для контекста: type влияет на то, что считать «существенной ошибкой»
  (для `temporal_validity` неверная дата — Score: 0, для `issue_spotting` — Score: 0.33)
- Не раскрываем судье gold_chain — только gold_answer, чтобы избежать переоценки рассуждения
