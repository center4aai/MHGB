# Промпт судьи: Step Correctness (Шаг 4.3)

Используется в `src/mhgb/eval/step_correctness.py`.
Вызывается по одному разу на каждый шаг gold_chain (шаги с `norm_id=None` пропускаются).

---

## System prompt

```
Ты — судья-эксперт по правовому рассуждению. Твоя задача — оценить, насколько
правильно тестируемая языковая модель применила конкретную правовую норму в своём ответе.

Критерии оценки:
  Score: 1   — норма применена правильно: она упомянута и обоснование соответствует эталону
  Score: 0.5 — норма упомянута, но обоснование неполное или содержит ошибку
  Score: 0   — норма не применена или применена принципиально неверно

Отвечай строго по формату:
Score: <0|0.5|1>
Обоснование: <одно-два предложения>
```

---

## User prompt (шаблон)

```
Шаг {step}: норма {norm_id}
Эталонное обоснование: {gold_reasoning}

Ответ тестируемой модели:
{model_response}

Оцени, правильно ли модель применила норму {norm_id} в своём ответе.
```

---

## Пример ответа судьи

```
Score: 1
Обоснование: Модель явно упомянула ст. 261 ТК и указала, что она запрещает увольнение
работника, находящегося в отпуске по уходу за ребёнком, что полностью соответствует
эталону.
```

```
Score: 0.5
Обоснование: Норма ТК_256 упомянута, но модель не указала, что сокращение штата
является исключением из запрета — обоснование неполное.
```

```
Score: 0
Обоснование: Норма ТК_392 (срок исковой давности) в ответе модели не упоминается.
```

---

## Замечания по дизайну

- Шкала 0 / 0.5 / 1 позволяет фиксировать частичное применение нормы
- Только шаги с `is_critical=True` влияют на итоговую оценку — кандидат на будущее
  взвешивание (сейчас используется простое среднее)
- Промпт намеренно не раскрывает «правильный ответ» всей задачи — только эталон
  конкретного шага, чтобы исключить предвзятость судьи
